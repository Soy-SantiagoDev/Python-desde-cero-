# 🚀 Comenzar

Clona el repositorio.

```bash
git clone https://github.com/Soy-SantiagoDev/Python-desde-cero-.git
```

Entra al proyecto.

```bash
cd Python-desde-cero-
```

Abre Visual Studio Code.

```bash
code .
```
