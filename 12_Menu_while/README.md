# 📋 Proyecto 2 - Menú Interactivo

¡Bienvenido a tu segundo proyecto en Python!

En este proyecto crearás un menú interactivo utilizando el ciclo `while`.

El programa permanecerá en ejecución hasta que el usuario decida salir seleccionando la opción correspondiente.

Este tipo de programas es muy común en aplicaciones de consola, cajeros automáticos, sistemas de ventas y programas administrativos.

# 🤔 ¿Qué es un menú interactivo?

Un menú interactivo permite que el usuario seleccione diferentes opciones.

El programa continuará ejecutándose hasta que el usuario elija la opción de salir.

---

# 💻 Ejemplo de ejecución

```
=== MENÚ ===

1. Saludo
2. Mostrar mensaje
3. Salir

Selecciona una opción: 1

Hola, bienvenido.
```
