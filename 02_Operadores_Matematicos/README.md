# ➕ Operador de suma

Permite sumar dos o más valores.

```python
print(5 + 3)
```

Resultado

```
8
```

---

# ➖ Operador de resta

Permite restar un número de otro.

```python
print(10 - 4)
```

Resultado

```
6
```

---

# ✖ Operador de multiplicación

Multiplica dos números.

```python
print(5 * 2)
```

Resultado

```
10
```

---

# ➗ Operador de división

Divide un número entre otro.

```python
print(20 / 4)
```

Resultado

```
5.0
```

Observa que Python devuelve un número decimal (`float`) cuando utilizamos el operador `/`.

---

# 📦 Operaciones con variables

Los operadores también pueden utilizar variables.

```python
precio = 100
descuento = 20

print(precio - descuento)
```

Resultado

```
80
```

Esto hace que nuestros programas sean mucho más dinámicos.

---

# 📚 Resumen de operadores

| Operador | Descripción | Ejemplo |
|----------|-------------|----------|
| `+` | Suma | `5 + 3` |
| `-` | Resta | `8 - 2` |
| `*` | Multiplicación | `4 * 6` |
| `/` | División | `20 / 5` |
