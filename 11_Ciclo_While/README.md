# 🤔 ¿Qué es un ciclo `while`?

El ciclo `while` repite un bloque de código mientras una condición sea verdadera.

Cada vez que la condición se evalúa como `True`, el bloque se ejecuta nuevamente.

Cuando la condición deja de cumplirse, el ciclo termina.

---

# 💻 Ejemplo

```python
contador = 1

while contador <= 10:
    print(f"Repetición número {contador}")
    contador += 1

print("Fin del programa.")
```

---

# 📌 ¿Cómo funciona?

1. Se crea la variable `contador`.
2. Python verifica si `contador` es menor o igual a 10.
3. Si la condición es verdadera, ejecuta el bloque.
4. El contador aumenta en 1.
5. El proceso se repite hasta que la condición sea falsa.
