# 🤔 ¿Qué es `elif`?

La palabra clave `elif` significa **"else if"** (si no, entonces si).

Se utiliza cuando queremos comprobar varias condiciones una tras otra.

Python evaluará las condiciones en orden y ejecutará únicamente la primera que sea verdadera.

---

# 💻 Ejemplo

```python
nota = int(input("Ingresa tu calificación (0 - 100): "))

if nota >= 90:
    print("Excelente")
elif nota >= 70:
    print("Aprobado")
else:
    print("Reprobaste")
```

---

# 📌 ¿Cómo funciona?

Si la nota es:

- 95 → Excelente
- 80 → Aprobado
- 60 → Reprobaste

Solo se ejecutará uno de los bloques.
