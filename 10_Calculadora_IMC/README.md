# 🤔 ¿Qué es el IMC?

El Índice de Masa Corporal (IMC) es una medida que relaciona el peso y la altura de una persona.

La fórmula es:

```text
IMC = peso / (altura²)
```

Por ejemplo:

Peso: 70 kg

Altura: 1.75 m

Resultado:

```
IMC = 22.86
```

---

# 📊 Clasificación del IMC

| IMC | Clasificación |
|------|---------------|
| Menor de 18.5 | Peso bajo |
| 18.5 a 24.9 | Peso normal |
| 25 a 29.9 | Sobrepeso |
| 30 o más | Obesidad |
